# AI Notes

## How AI was used

AI was used throughout the implementation as a support tool while building the project. I used it mainly to understand implementation approaches, debug errors, improve error handling, and check parts of the code when I got stuck.

The code was run and tested multiple times during development, and AI was used to help understand and fix issues that came up during testing. I also used it to review the implementation and spot possible problems.

The final implementation was tested and adjusted manually based on the actual behavior of the project.
